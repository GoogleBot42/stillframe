Stillframe

E-ink picture frame firmware, built with ESPHome. Install it from this page over USB — no toolchain, no command line.

You need Chrome or Edge on a desktop computer. Installing uses Web Serial, which Safari and mobile browsers do not support. Connect the board over USB before you start.

EL133UF1 Spectra 6, 1600 × 1200, 6 colours. Soldered Inkplate 13 Spectra (ESP32-S3). Slide its power switch to ON — the blue LED must be lit, or the board never appears as a serial port.

Known issue — the very first install from the browser does not work on this board. Its CH340K USB bridge plus browser serial timing cannot get a factory-fresh board into download mode, and it has no BOOT button to force it. Do the first flash from a terminal instead (one esptool command). After that, browser installs work every time: hold the WAKE button ~8 seconds (or use the "Enter Flashing Mode" button in Home Assistant) and the board reboots itself into download mode, ready for the Install button here.

Install didn't take? Read this first.

Getting an ESP32-S3 into its download mode from a browser is a timing race, and USB-serial bridges lose it now and then. Nothing is broken — work down this list.

  • The "hold the BOOT button" advice depends on your board. TinyS3: it has one — hold BOOT, tap RESET, release BOOT, then click Install; that enters download mode every time. TinyPico and Inkplate 13 Spectra: there is no BOOT button — press RESET and click Install again the moment you let go.
  • Already running Stillframe v1.0.1 or newer? Then skip the timing race entirely: hold the WAKE button for ~8 seconds (or press the "Enter Flashing Mode" button in Home Assistant) and the board reboots itself into download mode, waiting for this installer — no RESET dance needed.
  • Just try again, two or three times. Each attempt is an independent roll — a run that fails twice often lands on the third.
  • Reload this page between attempts. After a failed connect the serial port can be left open, and the next attempt then dies immediately with "port is already open". A reload clears it.
  • Check the power switch. The Inkplate 13 Spectra has one, and its blue LED must be lit — with the board off there is no serial port to pick at all.
  • Use a USB-C data cable, plugged straight in. Charge-only cables carry no data, and hubs and docks add latency that loses the race.
  • Close anything else holding the port — serial monitors, the ESPHome dashboard, Arduino IDE, PlatformIO, a second browser tab of this page.
  • On macOS, install the WCH driver. Apple's bundled CH34x driver does not work with this board's CH340K bridge. Install WCH's CH34xVPCDriver, then enable it under System Settings → General → Login Items & Extensions and replug.
  • Advanced: quit Chrome completely and relaunch it with --disable-features=SerialSplitDtrAndRts. Chrome 141 and later split the reset pulse into two USB transfers, which makes the race harder to win.
  • The reliable fallback: flash from a terminal with esptool — it drives the reset lines in one atomic system call and effectively always works. For the Inkplate 13 Spectra (adjust the manifest URL and port for other boards): 
    curl -LO https://googlebot42.github.io/stillframe/firmware/spectra13-inkplate/stillframe-spectra13-esp32s3.factory.bin
esptool --chip esp32s3 --port /dev/ttyUSB0 --baud 921600 \
  --before default-reset --after hard-reset \
  write-flash -z --flash-mode keep --flash-freq keep --flash-size keep \
  0x0 stillframe-spectra13-esp32s3.factory.bin
    More detail in the project README. After this one flash, browser installs work reliably via the firmware's flashing-mode button (hold WAKE ~8s).

How it goes

  1. Plug the board into your computer with a USB data cable, and switch it on if it has a power switch — an Inkplate 13 Spectra will not show up as a serial port until its blue power LED is lit.
  2. Pick your device above and press Install, then choose the board's serial port in the browser dialog.
  3. When flashing finishes, the same dialog offers Connect to Wi-Fi. Enter your network there — the credentials go straight to the device over USB.
  4. Open Home Assistant. The frame appears under Settings → Devices & Services as a discovered ESPHome device; click Configure to adopt it.

Updates come over Wi-Fi. Once adopted, each frame gets a Firmware entity in Home Assistant that installs new releases from this site over the air — you only need the USB cable once. Because a frame sleeps almost all of the time, give it a window first: turn its Prevent Deep Sleep switch on (or hold the wake button while it boots), and it will check this site and stay up long enough to install.

Notes

The frame spends nearly all of its time in deep sleep, waking on a timer to pull a fresh image. How often is up to you: the Sleep Duration number entity in Home Assistant sets the wake period in minutes, and every wake is a full panel refresh, so longer is kinder to the battery. If you need the frame to stay awake — to read its logs or install firmware — hold the wake button while it boots, or flip the Prevent Deep Sleep switch in Home Assistant before its next wake-up.

Images come from a Stillframe server on your own network, which crops, resizes and dithers pictures for the panel. Point the device at it from Home Assistant after adopting.
